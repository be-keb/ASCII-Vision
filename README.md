# ASCII Vision

An open-source, browser-based tool that turns your live camera feed into ASCII art in real time. Pick a theme and download your creation as a `.txt` file.

[Try it here ->](https://be-keb.github.io/ASCII-Vision/)

## Features

- **Live camera feed** rendered as ASCII art in real time
- **4 built-in themes** to choose from
- **Download as `.txt`** — save your ASCII art locally
- **Runs entirely in the browser** — no installs, no uploads, no server
- **Open source** — free to use, modify, and share

## How to Use

1. Open the tool in your browser.
2. Allow camera access when prompted.
3. Pick a theme from the menu.
4. Watch the live ASCII art update in real time.
5. Click **Download** to save it as a `.txt` file.
